Recap

Recap: Bayesian decision making

What do we need to know to find the Bayesian strategy?

\[ R(\cq) = \sum_{\cx \in \cX} \sum_{\ck \in \cK} \cpXK(\cx, \ck)\; \cW(\ck, \cq(\cx)), \qquad \cq^* = \arg\min_{\cq:\, \cX \to \cD} R(\cq) \]

We need

  • \(\cp(\cx \mid \ck)\): likelihoods
  • \(\cp(\ck)\): priors
  • \(\cW(\ck, \cd)\): the loss

With the 0/1 loss

\(\cq^*(\cx) = \arg\max_{\ck} \cp(\ck \mid \cx)\)

\(\phantom{\cq^*(\cx)} = \arg\max_{\ck} \cp(\cx \mid \ck)\, \cp(\ck)\)

The prior is inside the posterior.

Recap: the reject option

When is it better to answer "I do not know"?

Decisions \(\cD = \cK \cup \{\text{not known}\}\) and the loss

\[ \cW(\ck, \cd) = \begin{cases} 0 & \text{if } \cd = \ck \\ 1 & \text{if } \cd \ne \ck \text{ and } \cd \ne \text{not known} \\ \varepsilon & \text{if } \cd = \text{not known} \end{cases} \]

The Bayesian strategy becomes

\[ \cq^*(\cx) = \begin{cases} \arg\max_{\ck} \cp(\ck \mid \cx) & \text{if } 1 - \max_{\ck} \cp(\ck \mid \cx) < \varepsilon \\ \text{not known} & \text{otherwise} \end{cases} \]

Discrete minimax

The minimax task

\[ \cq^* = \arg\min_{\cq:\, \cX \to \cK}\; \max_{\ck \in \cK}\; \epsilon(\ck), \qquad \epsilon(\ck) = \sum_{\cx:\, \cq(\cx) \ne \ck} \cp(\cx \mid \ck) \]

What is \(\epsilon(\ck)\) in words? What do we need, and what is missing compared with Bayes?

For two classes: decide by the likelihood ratio \[ \cr(\cx) = \frac{\cp(\cx \mid \cone)}{\cp(\cx \mid \ctwo)}, \qquad \cq(\cx) = \begin{cases} \cone & \text{if } \cr(\cx) > \cl \\ \ctwo & \text{if } \cr(\cx) \le \cl \end{cases} \]

One number gives the whole strategy: the threshold \(\cl\).

Lecture: the inverse ratio \(\cp(\cx \mid \ctwo) / \cp(\cx \mid \cone)\) with the threshold \(\mu\). Assignment: this form.

Continuous minimax

Minimax for continuous \(\cx\)

\[ \cq^* = \arg\min_{\cq:\, \cX \to \cK}\; \max_{\ck \in \cK}\; \epsilon(\ck), \qquad \epsilon(\ck) = \int_{\cx:\, \cq(\cx) \ne \ck} \cp(\cx \mid \ck)\, d\cx \]

We move the threshold \(\cl\). What happens to \(\eone\), \(\etwo\) and their maximum?

For continuous \(\cx\) the errors change continuously, one grows and the other shrinks. The optimum is where \(\;\eone = \etwo\).

Derivation: example I

By symmetry the regions are \(\cone \mid \ctwo \mid \cone\) with the boundaries \(\pm t\):

\[ \eone = \int_{-t}^{t} |\cx|\, d\cx = 2 \int_{0}^{t} \cx\, d\cx = t^2 \]

\[ \etwo = 2 \int_{t}^{1} (1 - \cx)\, d\cx = (1 - t)^2 \]

\[ \eone = \etwo: \quad t^2 = (1 - t)^2 \quad \text{gives} \quad t = \tfrac{1}{2} \]

\[ \cl^* = \cr(\tfrac{1}{2}) = 1, \qquad \eone = \etwo = \mathbf{\tfrac{1}{4}} \]

\[ \cq^*(\cx) = \begin{cases} \ctwo & \text{if } |\cx| \le \tfrac{1}{2} \\ \cone & \text{otherwise} \end{cases} \]

Example III: two normal distributions

\(\cp(\cx \mid \ck)\) normal with \(\mone = -5,\ \sone = 2,\ \mtwo = 1,\ \stwo = 5\). Find the minimax strategy.

A threshold \(\cl\) on \(\cr(\cx)\) gives two boundaries \(t_1, t_2\). How do we compute them?

Regions \(\ctwo \mid \cone \mid \ctwo\) and the errors for \(\cl = 1\). How do we get \(\eone = \etwo\)?

Derivation: from \(\cl\) to the boundaries

We decide \(\cone\) where \(\;\dfrac{\cp(\cx \mid \cone)}{\cp(\cx \mid \ctwo)} \ge \cl\):

\[ \frac{\stwo}{\sone}\, \exp\!\left( -\frac{(\cx - \mone)^2}{2\sone^2} + \frac{(\cx - \mtwo)^2}{2\stwo^2} \right) \;\ge\; \cl \]

Take the logarithm: the same inequality \(a\cx^2 + b\cx + c \ge 0\) as in Lab 2 \[ -\frac{(\cx - \mone)^2}{2\sone^2} + \frac{(\cx - \mtwo)^2}{2\stwo^2} \;\ge\; \ln\!\left( \frac{\sone}{\stwo} \cdot \cl \right) =: L \]

\(a = \sone^2 - \stwo^2\) \(b = 2(\stwo^2 \mone - \sone^2 \mtwo)\) \(c = \sone^2 \mtwo^2 - \stwo^2 \mone^2 - 2 \sone^2 \stwo^2 L\)

Lab 2 had \(\dfrac{\cp(\ctwo)}{\cp(\cone)}\) in place of \(\cl\): this is the Bayesian strategy for \(\;\cp(\cone) = \dfrac{1}{1 + \cl}\)

Derivation: the errors of the strategy

For \(\sone < \stwo\) the regions are \(\ctwo \mid \cone \mid \ctwo\) with the boundaries \(t_1 < t_2\).

With the distribution functions \(F_{\cone}\), \(F_{\ctwo}\) (norm.cdf): \[ \eone = \int_{-\infty}^{t_1} \cp(\cx \mid \cone)\, d\cx + \int_{t_2}^{\infty} \cp(\cx \mid \cone)\, d\cx = 1 - \big( F_{\cone}(t_2) - F_{\cone}(t_1) \big) \]

\[ \etwo = \int_{t_1}^{t_2} \cp(\cx \mid \ctwo)\, d\cx = F_{\ctwo}(t_2) - F_{\ctwo}(t_1) \]

\(\eone = \etwo\) has no closed-form solution for normal distributions. We have to search for \(\cl\) numerically.

Minimax and Bayes

The risk of a fixed strategy

We fix a strategy \(\cq\). How does its risk change when the prior changes?

\[ R(\cq) = \sum_{\ck} \int_{\cx:\, \cq(\cx) \ne \ck} \cpXK(\cx, \ck)\, d\cx = \sum_{\ck} \cp(\ck) \underbrace{\int_{\cx:\, \cq(\cx) \ne \ck} \cp(\cx \mid \ck)\, d\cx}_{\epsilon(\ck)} \]

For two classes, with \(\cp(\ctwo) = 1 - \cp(\cone)\): \[ R(\cq) = \cp(\cone)\, \eone + \big( 1 - \cp(\cone) \big)\, \etwo = \cp(\cone)\, \big( \eone - \etwo \big) + \etwo \]

Linear in \(\cp(\cone)\), from \(\etwo\) at \(\cp(\cone) = 0\) to \(\eone\) at \(\cp(\cone) = 1\). Worst case: \(\max(\eone, \etwo)\)

Minimax as the worst-case Bayes

For each prior \(\cp(\cone)\): the risk of its own optimal Bayesian strategy (example III)

The strategy designed for \(\cp(\cone) = 0.6\), used everywhere: a line touching the curve

Its ends are \(\etwo\) (left) and \(\eone\) (right). We mark both above its prior

The same for the strategies of all priors from 0 to 1: the points draw \(\eone\) and \(\etwo\)

The worst case of every Bayesian strategy: \(\max(\eone, \etwo)\)

Minimax: the Bayesian strategy for \(p^*(\cone)\), its line is horizontal, \(\eone = \etwo\)

g = ({m1: -5, s1: 2, m2: 1, s2: 5})
erf = x => {
  const s = Math.sign(x), a = Math.abs(x), t = 1 / (1 + 0.3275911 * a);
  return s * (1 - (((((1.061405429 * t - 1.453152027) * t) + 1.421413741) * t - 0.284496736) * t + 0.254829592) * t * Math.exp(-a * a));
}
cdf = (x, m, s) => 0.5 * (1 + erf((x - m) / (s * Math.SQRT2)))
bayesStrategy = p1 => {
  if (p1 <= 0) return {t1: NaN, t2: NaN, e1: 1, e2: 0};
  if (p1 >= 1) return {t1: -Infinity, t2: Infinity, e1: 0, e2: 1};
  const L = Math.log(g.s1 / g.s2 * (1 - p1) / p1);
  const a = g.s1 ** 2 - g.s2 ** 2, b = 2 * (g.s2 ** 2 * g.m1 - g.s1 ** 2 * g.m2);
  const c = g.s1 ** 2 * g.m2 ** 2 - g.s2 ** 2 * g.m1 ** 2 - 2 * g.s1 ** 2 * g.s2 ** 2 * L;
  const d = b * b - 4 * a * c;
  if (d <= 0) return {t1: NaN, t2: NaN, e1: 1, e2: 0};
  const r = [(-b - Math.sqrt(d)) / (2 * a), (-b + Math.sqrt(d)) / (2 * a)].sort((u, v) => u - v);
  return {t1: r[0], t2: r[1],
          e1: 1 - (cdf(r[1], g.m1, g.s1) - cdf(r[0], g.m1, g.s1)),
          e2: cdf(r[1], g.m2, g.s2) - cdf(r[0], g.m2, g.s2)};
}
