From Bayes to log odds

Bayesian strategy, 0/1 loss, two classes

\[ \cq^*(\cx) = \arg\max_{\ck} \cp(\ck \mid \cx) \]

\[ \cq^*(\cx) = \cone \quad\text{if}\quad \cp(\cone \mid \cx) > \cp(\ctwo \mid \cx) \;\Leftrightarrow\; \frac{\cp(\cone \mid \cx)}{\cp(\ctwo \mid \cx)} > 1 \;\Leftrightarrow\; \underbrace{\ln \frac{\cp(\cone \mid \cx)}{\cp(\ctwo \mid \cx)}}_{\ca(\cx)\ \text{log odds}} > 0 \]

Have you seen this ratio before?

Not the likelihood ratio \(\frac{\cp(\cx \mid \cone)}{\cp(\cx \mid \ctwo)}\) from minimax. This is the ratio of the posteriors, the odds.

The simplest choice: a linear log odds

Model the log odds directly, as a linear function of \(\cx\):

\[ \ca(\cx) = \ln \frac{\cp(\cone \mid \cx)}{\cp(\ctwo \mid \cx)} = w_0 + \mathbf{w}_1^\top \cx = \cw^\top \cbx \]

The bias is hidden in the vector: \(\cbx = [1, \cx]\), \(\cw = [w_0, \mathbf{w}_1]\).

For many problems the log odds is linear: e.g. two normal classes with the same covariance (later).

  1. Express \(\cp(\cone \mid \cx)\) and \(\cp(\ctwo \mid \cx)\) using \(\ca(\cx) = \cw^\top \cbx\).
  2. Show that \(1 - \csig(u) = \csig(-u)\) for \(\csig(u) = \frac{1}{1 + e^{-u}}\).

The logistic sigmoid

\(\cp(\cone \mid \cx) = \csig(\cw^\top \cbx)\)
\(\cp(\ctwo \mid \cx) = \csig(-\cw^\top \cbx)\)

  • a probability in \((0, 1)\)
  • \(\csig(0) = \frac{1}{2}\): the boundary
  • \(\csig(-u) = 1 - \csig(u)\)
  • \(\csig' = \csig\,(1 - \csig)\)

Does it look familiar?

\(\tanh u = 2\, \csig(2u) - 1\), a normal CDF (Lab 2)

What \(w_0\) and \(w_1\) do (1D)

\(\cp(\kp \mid x) = \csig(w_0 + w_1 x)\): larger \(|w_1|\), steeper, more confident.

\(w_0\) shifts the curve: \(\cp = \frac{1}{2}\) at \(x = -w_0 / w_1\).

The sign of \(w_1\): which class is on which side.

Derivation: the threshold in 1D

\[ \csig(w_0 + w_1 x) = \tfrac{1}{2} \;\Leftrightarrow\; w_0 + w_1 x = 0 \;\Leftrightarrow\; \boxed{x^* = -\frac{w_0}{w_1}} \]

\[ \cw = (1.5, -0.7): \qquad x^* = -\frac{1.5}{-0.7} \approx 2.14, \qquad w_1 < 0 \;\Rightarrow\; \cp(\kp \mid x) \text{ decreases} \]

\[ \cq(x) = \begin{cases} \kp & \text{if } x < 2.14 \\ \km & \text{if } x \geq 2.14 \end{cases} \]

More dimensions: a linear decision boundary

\(\cx \in \mathbb{R}^2\), \(\cp(\kp \mid \cx) = \csig(w_0 + w_1 x_1 + w_2 x_2)\): a surface over the plane.

A sigmoid along \(\cw\), constant across it: the contours are parallel lines.

Boundary \(\cw^\top \cbx = 0\): the surface cut at \(\frac{1}{2}\), a line (\(\mathbb{R}^D\): a hyperplane) \(\perp \cw\).

Logistic regression is a linear classifier: it can only cut the space by a hyperplane.

Learning \(\cw\)

Labels \(\pm 1\): one formula for both classes

\[ \begin{aligned} \cp(\kp \mid \cx) &= \csig(\cw^\top \cbx) \\ \cp(\km \mid \cx) &= \csig(-\cw^\top \cbx) \end{aligned} \]

\[ \Downarrow \] \[ \boxed{\cp(\ck \mid \cx) = \csig(\ck\, \cw^\top \cbx)} \]

Training set: \[ \cT = \{(\cx_1, \ck_1), \dots, (\cx_N, \ck_N)\} \] \[ \ck_i \in \{\kp, \km\} \]

How to find \(\cw\)? We have seen it last week.

Maximum likelihood for \(\cw\)

\[ \ell(\cw) = \sum_{i=1}^{N} \ln \cp(\cx_i, \ck_i \mid \cw) = \sum_{i=1}^{N} \ln \cp(\ck_i \mid \cx_i, \cw) + \underbrace{\sum_{i=1}^{N} \ln \cp(\cx_i)}_{\text{does not depend on } \cw} \]

\[ \cw^* = \arg\max_{\cw} \sum_{i=1}^{N} \ln \csig(\ck_i\, \cw^\top \cbx_i) = \arg\min_{\cw} \underbrace{\frac{1}{N} \sum_{i=1}^{N} \ln\big(1 + e^{-\ck_i\, \cw^\top \cbx_i}\big)}_{E(\cw)} \]

Result: \(E(\cw)\) is convex: one minimum, but no closed form. We need a numerical method.

Cross-entropy loss

Loss of one sample: \(-\ln \cp(\ck_i \mid \cx_i)\)

  • right side, confident: loss \(\approx 0\)
  • on the boundary: \(\ln 2\)
  • wrong side: grows linearly

A smooth, convex replacement of the 0/1 loss. We can take its gradient.

Cross-entropy, entropy, KL divergence

True distribution \(p\), model \(q\): \[ H(p, q) = -\sum_{\ck} p(\ck) \ln q(\ck) = \underbrace{-\sum_{\ck} p(\ck) \ln p(\ck)}_{\text{entropy } H(p)} + \underbrace{\sum_{\ck} p(\ck) \ln \frac{p(\ck)}{q(\ck)}}_{D_{\mathrm{KL}}(p \,\|\, q) \,\geq\, 0} \]

One sample, true label \(\ck_i\): \(p\) is one-hot, \(H(p) = 0\) \[ H(p, q) = -\ln q(\ck_i) = \ln\big(1 + e^{-\ck_i\, \cw^\top \cbx_i}\big) \]

Minimizing cross-entropy = minimizing KL = maximizing likelihood.

The gradient of \(E(\cw)\)

\[ E(\cw) = \frac{1}{N} \sum_{i=1}^{N} \ln\big(1 + e^{-\ck_i\, \cw^\top \cbx_i}\big) \]

  1. Compute the gradient \(\nabla E(\cw)\).
  2. Which samples push the most?

More problems like this: exercise book on CourseWare.

Derivation: the gradient

\[ \nabla E(\cw) = \frac{1}{N} \sum_{i=1}^{N} \frac{e^{-\ck_i\, \cw^\top \cbx_i}}{1 + e^{-\ck_i\, \cw^\top \cbx_i}}\, (-\ck_i\, \cbx_i) = -\frac{1}{N} \sum_{i=1}^{N} \csig(-\ck_i\, \cw^\top \cbx_i)\; \ck_i\, \cbx_i \]

\[ \boxed{\nabla E(\cw) = -\frac{1}{N} \sum_{i=1}^{N} \big(1 - \cp(\ck_i \mid \cx_i)\big)\, \ck_i\, \cbx_i} \qquad \text{badly classified samples push the most} \]

\[ \text{Hessian:}\quad H(\cw) = \frac{1}{N} \sum_{i=1}^{N} \cp(\kp \mid \cx_i)\, \cp(\km \mid \cx_i)\; \cbx_i \cbx_i^\top \;\succeq\; 0 \quad\Rightarrow\quad E \text{ is convex} \]

Gradient descent: the step size

\(\cw \leftarrow \cw - \eta\, \nabla E(\cw)\). Step \(\eta\) too small: slow.

Just right: a few steps to the minimum.

Too large: jumps over the minimum, may diverge.

Gradient descent with an adaptive step

w = w_init
step_size = 1.0
E, g = compute_E_and_gradient(X, k, w)
while not TERMINATION_CONDITION:
    E_new, g_new = compute_E_and_gradient(X, k, w - step_size * g)
    if E_new < E:        # success: accept, larger step
        w -= step_size * g
        E, g = E_new, g_new
        step_size *= 2
    else:                # failure: smaller step
        step_size /= 2
return w
  • accept the step only if \(E\) decreases
  • success: double the step
  • failure: halve it
  • stop: \(\|\cw_\text{new} - \cw_\text{prev}\| \leq \varepsilon\)

The gradient is normalized by \(\frac{1}{N}\): the step size does not depend on the number of samples.

Generative vs discriminative

When is the log odds linear?

Two normal classes, the same \(\Sigma\): \[ \ca(\cx) = \ln \frac{\cp(\cx \mid \cone)\, \cp(\cone)}{\cp(\cx \mid \ctwo)\, \cp(\ctwo)} \]

The terms \(\cx^\top \Sigma^{-1} \cx\) cancel: \[ \ca(\cx) = \underbrace{(\mu_1 - \mu_2)^\top \Sigma^{-1}}_{\mathbf{w}_1^\top} \cx + w_0 \]

Equal variances: logistic regression is the exact model.

Same mean, different variances: a quadratic log odds, logistic regression fails.

Two classes, \(\cx \in \mathbb{R}^D\):

  • logistic regression: \(\cw\)

Derivation: number of parameters

Take-away for the lab

  • Discriminative: model \(\cp(\ck \mid \cx)\) directly, no \(\cp(\cx \mid \ck)\)
  • Linear log odds \(\iff\) \(\cp(\ck \mid \cx) = \csig(\ck\, \cw^\top \cbx)\), a linear boundary
  • ML \(=\) min of the cross-entropy: convex, solved by gradient descent
  • Separable data: \(\|\cw\| \to \infty\), use a prior (regularization) or Bayes
  • Softmax for more classes, lifting for nonlinear boundaries: towards neural networks
